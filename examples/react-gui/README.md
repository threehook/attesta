# zk-puoi example GUI

Demonstrates the zk-puoi authorization flow end to end: mock login, a mock Verifiable Credential wallet, and a
resource request that builds a real Groth16 proof in the browser (via `@zk-puoi/client`) and submits it to the
backend's `/v1/authorize`.

See the repo root [README](../../README.md) for the architecture, and its "examples/react-gui" section under
Development workflow for setup and run commands.
